# ChessPal

Offline chess practice and opening guides for beginners who already know the rules. Formerly Rookie Reps ([why the name changed](docs/decisions/0002-chesspal-name.md)).

## MVP

- **Practice:** 10 puzzles per workout at your level (two easier, six at level, two harder), then keep practicing without a daily limit.
- **1,059 puzzles:** eight themes (mate in one, back-rank mate, mate in two, hanging pieces, forks, pins, skewers, discovered attacks) at Beginner, Easy and Medium levels; legal moves, progressive hints, solution replay and explanations.
- **Skills:** a concept card and three rounds per theme (warm-up, at your level, an unlabeled test). Clear a round with four of five solved without help.
- **Strengths and weaknesses:** your strongest theme and the one worth practicing, on Results and Progress; your daily round includes the weaker one.
- **Board vision:** 30-second rounds of finding squares by name, from either side.
- **Learn:** Italian Game, Caro-Kann Defence and Queen’s Gambit, with three example branches per guide. Follow a demonstration, practice with guidance, then recall without move notes or hints.
- **Apply the idea:** six original exercises use unfamiliar positions. Try the stated goal, see its explanation after answering, and return for delayed recall.
- **Next step:** Home helps you resume a lesson, return for a due recall, or apply an opening idea in a new position.
- **Progress:** independent and assisted puzzle solves and lesson recalls, practiced guides, activity and streaks. Completed lessons count toward activity alongside workouts. Workouts, branch positions and exercises resume automatically.
- **Recall:** scheduled reviews return after a delay, including puzzles previously solved independently. Workouts mix due reviews with fresh practice.
- **Daily route:** five themed puzzles a day with two safe-or-steep forks, scored against your own earlier runs.
- **Settings:** light, dark or system appearance and optional haptic feedback.
- No account, server, subscription or internet connection needed for learning. Opening references open in your browser.

Current scope: [docs/MVP.md](docs/MVP.md). Puzzle sources and engine checks: [docs/content-pipeline.md](docs/content-pipeline.md).

## Run locally

Use Node 22.13 or newer (see `.nvmrc`) and an Android emulator or a phone with a matching Expo Go version.

```bash
npm ci
npm start
```

Scan the QR code in Expo Go, or press `a` for an emulator. `npm run android` creates and installs a native development build with an Android SDK and JDK installed. `npm run web` opens a browser preview.

## Verify and build

```bash
npm run check
npx expo export --platform android
```

The check runs TypeScript, ESLint, formatting and Jest, including actual board interactions, complete workouts, all three guides, Home learning recommendations, persisted state and the legality of every bundled puzzle. CI also exports the production Android bundle. Device validation is tracked in [docs/DEVICE-TESTING.md](docs/DEVICE-TESTING.md).

`npm run content:verify` rebuilds puzzle content from a candidate import and verifies learner moves with Stockfish. Stockfish is a development tool; the app bundles only the resulting JSON.

`npm run content:verify-openings` checks all opening branches and reruns Stockfish verification of the six transfer exercises without rewriting their metadata. [Opening practice sources](content/OPENING-PRACTICE-SOURCES.md) explains the goal-specific answers and finite-depth checks.

```bash
npx eas-cli build --platform android --profile preview
npx eas-cli build --platform android --profile production
```

The EAS profiles produce an installable preview APK and a store AAB respectively. EAS builds require your Expo account and project setup. Publishing to Google Play also requires your developer account, signing credentials and store submission.

Native directories are generated by Expo prebuild and excluded from Git. Progress stays on the device; uninstalling or clearing app data removes it.

## Structure

```text
content/         # bundled puzzles, skill cards and starter guides
scripts/content/ # import and engine verification
src/
  app/           # Expo Router screens
  chess/         # chess.js boundary and legal move adapter
  components/    # board, Chessnut pieces, icons and shared UI (cards, buttons, rows)
  constants/     # design tokens: colors, fonts, spacing, elevation
  content/       # typed content access and validation
  learning/      # pure branch, transfer and lesson recall logic
  skills/        # pure skill ladder rules and theme strengths
  vision/        # pure board vision round rules
  workout/       # pure practice session logic
  progress/      # persisted app state
  storage/       # schema validation and serialized local writes
docs/            # current scope, content pipeline and decisions
licenses/        # notices for bundled third-party artwork and icons
```
